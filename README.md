# らっかせい！

花を落として同じ色を4個以上つなげる、スマートフォン縦画面向けの落ちものパズルです。

## Phase 2

- 黄色・ピンク・紫の2個組の花
- 左右移動、90度回転、高速落下
- 4個以上の同色消去、重力、連鎖、スコア
- 地上6列×12段と、将来の落花生用の地下6列×6段
- タッチ操作とキーボード操作
- 1連鎖目で消去を成立させた列への落花生生成
- 子房柄と落花生生成位置の予告・出現演出

2連鎖目以降の複数生成、落花生の収穫、タイトル画面、正式な結果画面は今後のPhaseで追加します。

## ローカル起動

```bash
npm install
npm run dev
```
